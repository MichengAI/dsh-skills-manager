## 目标与业务边界

修复技能目录管理中的路径穿越、自覆盖导入和跨站写入风险；不恢复技能格式检查，也不改变公共 Agent 技能目录只读边界。

## 已完成内容

- 拒绝 `.`、`..`、路径分隔符及 Windows 会归一化为目录的技能名称，并在解析后校验路径仍在技能根内。
- 拒绝导入来源与 DSH 技能目录相同、互为父子目录的情况；导入时拒绝符号链接。
- 导入与覆盖均先复制到临时同级路径，成功后再替换；替换失败时尽力恢复旧条目。
- 写接口要求 `application/json` 与客户端请求标记，补充 400、403、413、415、404 路由验证。
- 启停改为原子写入；缺少完整 frontmatter 时返回错误而不是静默成功。
- 批量导入拦截规范化后同名的多个来源；导入全跳过时前端明确提示未导入。
- 增加日志单文件 1 MiB 轮转，补齐客户端运行时 peer 依赖。
- 单测扩展至 81 项，包含 HTTP 集成、路径穿越、重叠来源、CRLF、平铺删除与同名批量导入。
