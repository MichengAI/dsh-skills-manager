## 目标与业务边界

通过 GitHub Actions 在推送 `v*` 版本标签时自动测试并发布至官方 npm registry；不发布至 GitHub Packages，也不保存长期 npm 写入令牌。

## 已完成内容

- 新增 `.github\workflows\publish.yml`，使用 GitHub 托管运行器、Node 24 与 npm Trusted Publishing（OIDC）。
- 工作流按“测试成功后发布”的顺序执行，并限制为 `v*` 标签触发。
- 为 OIDC 权限、测试与发布命令增加回归断言。
- 更新工程交付文档和当前待办。
