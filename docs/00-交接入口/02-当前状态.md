# 当前状态

更新时间：2026-08-30（Asia/Shanghai）

## 当前阶段

版本 `0.1.31` 支持从活动 Session 的最近 Git 根发现项目 Skills。项目 `.dsh/skills` 可在设置页创建、启停、移入统一回收站并恢复到原项目；项目 `.agents/skills` 保持只读，项目加载与 Session catalog 仍由 DSH 官方 filesystem provider 负责。

项目写入边界已加固：无 `.git` 的 cwd 不再回落为项目根；与任一用户技能根重叠或通过符号链接/reparse point 重定向的项目来源不会展示，也不能写入。技能根本身的链接不会被列表或详情跟随。

## 活动迭代

项目级 Skill 管理与安全边界修复已经完成，核心测试与本地化契约测试均通过。

## 有效风险

- 斜杠菜单刷新仍借用宿主已转发的 `agent-preset/selected`；后续若 DSH 正式转发 `skills/change`，应切换为官方事件。
- 浏览器自动化端到端回归尚未纳入持续集成，当前依赖核心测试、本地化契约测试与本机 DSH Web 冒烟。
- `core.js` 仍集中承载多类核心职责；属于后续可维护性改进，不影响本次缺陷修复。
- 项目 DSH 当前支持表单新建，但上传导入与覆盖仍只作用于 `$DSH_HOME\skills`。
