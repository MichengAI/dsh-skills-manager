# 项目概览

更新时间：2026-08-16 17:25（Asia/Shanghai）

## 定位

DeepSeek Harness 的 Web 插件，在设置侧边栏提供「Skill 管理」面板，管理用户级技能。

## 当前阶段

I023 已完成并归档；当前处于维护阶段。

## 核心能力

- 双目录展示：`$DSH_HOME\skills` 与 `$DSH_AGENTS_HOME\skills`。
- 列表：名字、bundle/flat 形态、启停状态与简介。
- 启用/停用：仅改写 DSH 技能的 `disable-model-invocation` 与 `user-invocable`，同时控制模型调用和 `/` 手动调用。
- frontmatter 完整性：启停不会重写其他元数据，支持正确展示 YAML 块文本描述。
- 原生文件选择上传：仅上传到 `$DSH_HOME\skills`；优先选择 `SKILL.md`，取不到文件路径时可选择插件目录；选取状态与错误在上传弹窗内显示，同名（含跨形态）时确认覆盖。
- 删除：仅删除 DSH 根目录内的目标插件，操作前确认；公共 Agent 目录不可删除。

## 稳定边界

- 公共 `$DSH_AGENTS_HOME\skills` 为只读目录，只允许展示，不提供启用、停用、上传、覆盖或删除。
- 覆盖与删除只作用于 `$DSH_HOME\skills` 内同名条目。
- 不做格式检查或自动修复。
- host 端零第三方运行时依赖，可放置于任意位置。
