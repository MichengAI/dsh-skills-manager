# 项目概览

更新时间：2026-09-02 00:22（Asia/Shanghai）

## 定位

DeepSeek Harness 的 Web 插件，在设置侧边栏提供「Skill 管理」面板，统一查看用户级与活动项目级技能，并管理用户 DSH 和项目 DSH 技能。

## 当前阶段

`0.1.31` 已完成项目 Skill 发现与管理：活动项目 `.dsh/skills` 支持创建、启停、移入回收站和恢复，并补齐 Git 根、跨作用域重叠、链接根与跨盘移动安全边界。

`0.1.32` 将所有来源的逐 Skill 启停统一为 manager 本地三态策略，并把界面/API 的“已加载/已发现”统一为准确的“已启用/已停用”调用状态。

`0.1.33` 新增默认开启的 CC Switch 只读来源，并在受控边界内识别用户级只读来源之间的顶层 Skill 链接，按真实路径去重分发副本。

## 核心能力

- 双目录展示：`$DSH_HOME\skills` 与 `$DSH_AGENTS_HOME\skills`。
- 项目作用域管理：从活动 Session cwd 推导最近 Git 根；`<project>/.dsh/skills` 支持创建、非破坏性启停、移入回收站和恢复，`<project>/.agents/skills` 支持同样不改源文件的本地策略启停；跨项目同名条目互不串扰。
- 列表统一展示“已启用/已停用”的调用策略；设置页提供显式刷新，不把调用策略冒充为 Skill 正文已经载入 Session 的证据。
- 列表：名字、bundle/flat 形态、启停状态与简介；支持按名称、形态、简介和目录分类即时检索。
- 启用/停用：全部来源都通过 `$DSH_HOME\skills-manager\state.json` 的 manager 本地策略同时控制模型调用和 `/` 手动调用，不改写 `SKILL.md` 或单文件 Skill。
- frontmatter 完整性：启停不会重写其他元数据，支持正确展示 YAML 块文本描述。
- 单次上传导入：仅写入 `$DSH_HOME\skills`；同一弹窗支持 `.zip`、技能文件夹、单个 `SKILL.md` 与拖放，不读取绝对路径；选取状态与错误在弹窗内显示。
- 删除：用户 DSH 与活动项目 DSH 中的目标技能经确认后移入统一回收站，可恢复到原作用域；Agent 来源不可删除。

## 稳定边界

- 公共 `$DSH_AGENTS_HOME\skills` 源文件只读；启停只写 manager 状态，不提供上传、覆盖或删除。
- 项目 `.dsh/skills` 可创建、策略启停、删除和恢复；项目 `.agents/skills` 源文件只读但可通过同一 manager 本地状态启停，删除仍禁止。没有显式覆盖时，加载与 Session catalog 热刷新继续由 DSH 官方 filesystem provider 负责。
- 上传导入和覆盖仅作用于 `$DSH_HOME\skills`；项目 DSH 当前只支持新建，不支持上传导入或覆盖。
- 项目发现必须找到真实 `.git` 祖先；与任一用户技能根重叠、或通过符号链接/reparse point 重定向的项目来源不会展示，也不能写入。
- 不做格式检查或自动修复。
- host 端仅为 ZIP 解压直接依赖审计过的 `fflate`；其余逻辑使用 Node 内置模块。
