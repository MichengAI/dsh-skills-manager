# 项目概览

更新时间：2026-08-30（Asia/Shanghai）

## 定位

DeepSeek Harness 的 Web 插件，在设置侧边栏提供「Skill 管理」面板，管理用户级技能，并按活动 Session 工作区只读检查项目级技能。

## 当前阶段

I033 已完成：多 Agent 管理、详情诊断、回收站、对话创建与单次上传导入均已实机验证。

## 核心能力

- 双目录展示：`$DSH_HOME\skills` 与 `$DSH_AGENTS_HOME\skills`。
- 项目作用域展示：从活动 Session cwd 推导最近 Git 根，分别展示 `<project>/.dsh/skills` 与 `<project>/.agents/skills`；跨项目同名条目互不串扰。
- 项目条目只声明“已发现”；设置页提供显式刷新，不冒充 Session catalog 的“已加载”证据。
- 列表：名字、bundle/flat 形态、启停状态与简介；支持按名称、形态、简介和目录分类即时检索。
- 启用/停用：仅改写 DSH 技能的 `disable-model-invocation` 与 `user-invocable`，同时控制模型调用和 `/` 手动调用。
- frontmatter 完整性：启停不会重写其他元数据，支持正确展示 YAML 块文本描述。
- 单次上传导入：仅写入 `$DSH_HOME\skills`；同一弹窗支持 `.zip`、技能文件夹、单个 `SKILL.md` 与拖放，不读取绝对路径；选取状态与错误在弹窗内显示。
- 删除：仅删除 DSH 根目录内的目标插件，操作前确认；公共 Agent 目录不可删除。

## 稳定边界

- 公共 `$DSH_AGENTS_HOME\skills` 源文件只读；启停只写 manager 状态，不提供上传、覆盖或删除。
- 项目 Skill 只读展示和查看详情；加载、优先级和热刷新继续由 DSH 官方 filesystem provider 负责。
- 覆盖与删除只作用于 `$DSH_HOME\skills` 内同名条目。
- 不做格式检查或自动修复。
- host 端仅为 ZIP 解压直接依赖审计过的 `fflate`；其余逻辑使用 Node 内置模块。
