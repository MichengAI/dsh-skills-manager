# 项目概览

更新时间：2026-08-15 16:55（Asia/Shanghai）

## 定位

DeepSeek Harness 的 Web 插件，在设置侧边栏提供「Skill 管理」面板，管理用户级技能。

## 当前阶段

I006 已完成并归档；当前处于维护阶段。

## 核心能力

- 双目录展示：`$DSH_HOME\skills` 与 `$DSH_AGENTS_HOME\skills`。
- 列表：名字、bundle/flat 形态、启停状态与简介。
- 启用/停用：改写 frontmatter 的 `disable-model-invocation`，即时生效，无需重启。
- 原生文件选择上传：仅上传到 `$DSH_HOME\skills`；优先选择 `SKILL.md`，取不到文件路径时可选择插件目录；选取状态与错误在上传弹窗内显示，同名时确认覆盖。
- 删除：仅删除 DSH 根目录内的目标插件，操作前确认；公共 Agent 目录不可删除。

## 稳定边界

- 公共 `$DSH_AGENTS_HOME\skills` 只允许展示与启用/停用，不提供上传、覆盖或删除。
- 覆盖与删除只作用于 `$DSH_HOME\skills` 内同名条目。
- 不做格式检查或自动修复。
- host 端零第三方运行时依赖，可放置于任意位置。
