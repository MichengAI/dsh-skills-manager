# 文档编写规范

更新时间：2026-08-15 14:03（Asia/Shanghai）

## 适用范围

本规范适用于本项目 `docs\` 目录下的全部文档；全局默认规范见 `~/.dsh/AGENTS.md` 第十一节。

## 语言与编码

- 简体中文，UTF-8。
- 仅代码标识符、框架名、命令、参数保留英文。

## 目录结构

- `docs\00-交接入口\`：导航、概览、状态、待办、路线图、架构基线、文档规范。
- `docs\03-技术架构\`：当前有效的领域设计。
- `docs\07-迭代归档\YYYY\`：已完成/已取消的历史迭代。

只创建当前需要的目录和文档，禁止空模板与占位文档。

## 唯一事实源

同一信息只在一个位置写全，其余文档摘要并链接：

- 当前事实 → `02-当前状态.md`
- 未完成事项 → `03-待办与阻塞.md`
- 未来顺序 → `04-迭代路线图.md`
- 任务与验收 → 所属迭代的 `00-迭代总览.md`
- 当前有效设计 → `docs\03-技术架构\`
- 历史过程 → `docs\07-迭代归档\`

## 迭代编号

- 全项目唯一 `Ixxx`，取最大编号加一，不重复、不回收、不重排。
- 已完成/已取消移入 `docs\07-迭代归档\YYYY\Ixxx-迭代名称\`。

## 更新时间

事项变化时刷新 `更新时间：YYYY-MM-DD HH:mm（Asia/Shanghai）`。
