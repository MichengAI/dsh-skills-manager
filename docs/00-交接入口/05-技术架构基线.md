# 技术架构基线

更新时间：2026-08-15 23:54（Asia/Shanghai）

## 生效的技术硬约束

- 插件形态：标准 DSH Web 插件（`package.json` 元数据 + `exports["./client"]` AMD bundle + `cordis.patch.yml`）。
- 语言：纯 JavaScript（ESM），零构建步骤，不引入 TypeScript 编译链。
- host 半区零第三方运行时依赖（仅 `node:` 内置模块 + cordis 服务注入）。
- 客户端仅 `require("react")`，通过 `window.__ModuleLoader__` AMD 装载，注册 ID 必须与 `package.json.name` 完全一致；React 由宿主提供，禁止内联第二份实例。
- 数据源：`$DSH_HOME\skills` 与公共 `$DSH_AGENTS_HOME\skills`。
- 启用/停用：仅 DSH 根目录可改写 frontmatter 的 `disable-model-invocation` 与 `user-invocable`，同时控制模型和 `/` 手动调用；公共 Agent 根目录只读。
- 写入后：通过 `skills` 服务使目录缓存失效，通知客户端刷新 `/` 手动调用候选。
- 上传、覆盖和删除：仅作用于 `$DSH_HOME\skills`；客户端删除前确认，服务端再次拦截公共 Agent 目录删除。导入使用解析后的实际复制来源进行重叠校验，不接受符号链接，目录深度上限为 64；复制先写入临时同级路径再替换。上传优先使用原生文件选择，取不到 `File.path` 时回退到 `workspaces.pickDirectory()`，选择状态与错误显示在上传弹窗内。
- 弹窗：通过捕获阶段监听 `Escape`，每次只关闭当前最上层确认框或上传框，并阻止事件传至设置页。
- 不提供格式检查、自动修复或自定义目录选择器。
- 路由：host 挂载 `webServer` 前缀路由 `/api/dsh-skills-manager`；所有写接口要求 `application/json` 及 `x-dsh-skills-manager: 1` 请求标记。
- 插槽：客户端注册 `settings.section`，`id: skills-manager`，`order: 17`。
- 调用状态：无法识别的 `disable-model-invocation` 或 `user-invocable` 值显示为“配置异常”，仅 DSH 本地技能可通过“修复并启用”恢复默认调用状态。
- 国际化：UI 文案全部经 `locale` 服务的双语词典（zh/en）翻译；`settings.section` 注册声明 `locale` 命名空间，`label` 用 thunk 跟随语言切换。host 业务错误返回 `{ error, code, params }`，client 是唯一翻译点；协议错误带 `error.proto.*` 码。

## 关键服务依赖

| 平台 | 服务/注入 | 用途 |
|---|---|---|
| host | `webServer`、`skills` | 注册 HTTP 路由、写入后刷新技能目录 |
| client | `slots`、`locale`、`workspaces` | 注册设置分区；双语词典与翻译（`locale: NS` 注入 t seat）；原生目录选择回退 |
| client（构建期） | `@deepseek-ai/dsh-client-runtime`、`@deepseek-ai/dsh-client-ui-slots`、`@deepseek-ai/dsh-client-locale`、`@deepseek-ai/dsh-client-ui-workspace` | `package.json` 的 `dsh.client.inject` 声明 |
