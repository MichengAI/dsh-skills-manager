# 技术架构基线

更新时间：2026-08-26（Asia/Shanghai）

## 生效的技术硬约束

- 插件形态：标准 DSH Web 插件（`package.json` 元数据 + `exports["./client"]` AMD bundle + `cordis.patch.yml`）。
- 语言：纯 JavaScript（ESM），零构建步骤，不引入 TypeScript 编译链。
- host 半区零第三方运行时依赖（仅 `node:` 内置模块 + cordis 服务注入）。
- 客户端仅 `require("react")`，通过 `window.__ModuleLoader__` AMD 装载，注册 ID 必须与 `package.json.name` 完全一致；React 由宿主提供，禁止内联第二份实例。
- 数据源：`$DSH_HOME\skills`、`$DSH_AGENTS_HOME\skills`、Codex、Claude、Gemini 与 OpenCode 用户级 Skills 根。
- 加载优先级：DSH 本地保持官方 rank 400；manager provider 以 Agents 450、Codex 520、Claude 530、Gemini 540、OpenCode 550 提供只读候选，保证本地 DSH 优先。provider 同时注册在宿主全局层和每个存活 Agent 的作用域层；后者用于覆盖 Agent 预设自带的 filesystem provider，避免已停用技能从更近的预设层重新出现。
- 启用/停用/删除：只有 DSH 根目录会改写自身文件；外部来源启停写入 `$DSH_HOME\skills-manager\state.json`。解析条目用 lstat，且 realpath 必须仍在技能根内，禁止经符号链接写出根外。
- 写入后：通过 `skills` 服务使目录缓存失效；并补发 `commands/change` 与带当前预设的 `agent-preset/selected`，让 Web `/` 菜单立刻重拉 `skills.list`。官方 `skills/change` 尚未转发到浏览器。
- 创建、导入和删除：仅作用于 `$DSH_HOME\skills`；创建拒绝覆盖，导入保留原有重叠/符号链接/64 层深度/临时替换约束。删除改为移动到 manager 回收站，支持恢复与二次永久删除；Windows 瞬时目录占用只重试 `EACCES`、`EBUSY`、`EPERM`。
- 弹窗：共享 `Modal` 在处理 `Escape` 时同时执行 `preventDefault`、`stopPropagation` 与原生 `stopImmediatePropagation`，每次只关闭当前最上层确认框或上传框，不把按键继续传给设置页。上传、目录浏览、覆盖、删除确认都是插件自有前台遮罩卡片，用更高优先级样式覆盖宿主 `[role=dialog]` 拉满。
- 导入选择：保留浏览器原生 `SKILL.md` 文件选择；若运行环境不暴露 `File.path`，自动切换到插件内 680px 目录浏览器。目录浏览通过带客户端标记的 POST `/browse` 获取本机目录层级，不调用 `workspaces.pickDirectory()`，因此不会出现 Node 宿主窗口、失焦或重复系统对话框。
- 提供正文详情、frontmatter 与只读诊断；不自动修复外部源文件。
- 路由：host 挂载 `webServer` 前缀路由 `/api/dsh-skills-manager`。全部接口（含 GET `/state`）校验 Host 为 `localhost` / `127.0.0.1` / `[::1]`；POST 接口（含只读 `/browse`）要求 `application/json` 及 `x-dsh-skills-manager: 1`。
- 信任边界：本接口只信任 loopback 来源，不得把 `webServer` 暴露到非本机地址。`/import` 的 `source` 是用户选定的本机绝对路径，服务端校验形态、符号链接、深度和与目标目录重叠，不按归属目录白名单拦截。
- 插槽：客户端注册 `settings.section`，`id: skills-manager`，`order: 17`。
- 调用状态：无法识别的 `disable-model-invocation` 或 `user-invocable` 值显示为“配置异常”，仅 DSH 本地技能可通过“修复并启用”恢复默认调用状态。
- 国际化：UI 文案全部经 `locale` 服务的双语词典（zh/en）翻译；`settings.section` 注册声明 `locale` 命名空间，`label` 用 thunk 跟随语言切换。host 业务错误返回 `{ error, code, params }`，client 是唯一翻译点；协议错误带 `error.proto.*` 码，非法 Host 与缺少写请求标记分码。导入回滚失败和备份未清理也带可翻译码，不把 Node 系统码抄到业务 `code` 上。

## 关键服务依赖

| 平台 | 服务/注入 | 用途 |
|---|---|---|
| host | `webServer`、`skills`、`tools` | 注册 HTTP 路由、外部 provider、对话创建工具，并刷新技能目录与 Web `/` 菜单 |
| client | `slots`、`locale` | 注册设置分区；双语词典与翻译（`locale: NS` 注入 t seat） |
| client（构建期） | `@deepseek-ai/dsh-client-runtime`、`@deepseek-ai/dsh-client-ui-slots`、`@deepseek-ai/dsh-client-locale` | `package.json` 的 `dsh.client.inject` 声明 |
