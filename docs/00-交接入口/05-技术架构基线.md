# 技术架构基线

更新时间：2026-08-17 12:40（Asia/Shanghai）

## 生效的技术硬约束

- 插件形态：标准 DSH Web 插件（`package.json` 元数据 + `exports["./client"]` AMD bundle + `cordis.patch.yml`）。
- 语言：纯 JavaScript（ESM），零构建步骤，不引入 TypeScript 编译链。
- host 半区零第三方运行时依赖（仅 `node:` 内置模块 + cordis 服务注入）。
- 客户端仅 `require("react")`，通过 `window.__ModuleLoader__` AMD 装载，注册 ID 必须与 `package.json.name` 完全一致；React 由宿主提供，禁止内联第二份实例。
- 数据源：`$DSH_HOME\skills` 与公共 `$DSH_AGENTS_HOME\skills`。
- 启用/停用/删除：仅 DSH 根目录可改写；解析条目用 lstat，且 realpath 必须仍在技能根内，禁止经符号链接写出根外。公共 Agent 根目录只读。技能名不得以点开头，避免把崩溃残留扫成技能。
- 写入后：通过 `skills` 服务使目录缓存失效；并补发 `commands/change` 与带当前预设的 `agent-preset/selected`，让 Web `/` 菜单立刻重拉 `skills.list`。官方 `skills/change` 尚未转发到浏览器。
- 上传、覆盖和删除：仅作用于 `$DSH_HOME\skills`；客户端删除前确认，服务端再次拦截公共 Agent 目录删除。导入使用 realpath 后的来源与目标做重叠校验，不接受符号链接，目录深度上限为 64；全 skip 时不创建目标根；复制先写入临时同级路径再替换。上传优先使用原生文件选择，取不到 `File.path` 时回退到 `workspaces.pickDirectory()`，选择状态与错误显示在上传弹窗内。
- 弹窗：通过捕获阶段监听 `Escape`，每次只关闭当前最上层确认框或上传框，并阻止事件传至设置页。上传、覆盖、删除确认都是插件自有遮罩卡片（约 480px 宽、内容高度），用更高优先级样式覆盖宿主 `[role=dialog]` 拉满。
- 不提供格式检查、自动修复或自定义目录选择器。
- 路由：host 挂载 `webServer` 前缀路由 `/api/dsh-skills-manager`。全部接口（含 GET `/state`）校验 Host 为 `localhost` / `127.0.0.1` / `[::1]`；写接口额外要求 `application/json` 及 `x-dsh-skills-manager: 1`。
- 信任边界：本接口只信任 loopback 来源，不得把 `webServer` 暴露到非本机地址。`/import` 的 `source` 是用户选定的本机绝对路径，服务端校验形态、符号链接、深度和与目标目录重叠，不按归属目录白名单拦截。
- 插槽：客户端注册 `settings.section`，`id: skills-manager`，`order: 17`。
- 调用状态：无法识别的 `disable-model-invocation` 或 `user-invocable` 值显示为“配置异常”，仅 DSH 本地技能可通过“修复并启用”恢复默认调用状态。
- 国际化：UI 文案全部经 `locale` 服务的双语词典（zh/en）翻译；`settings.section` 注册声明 `locale` 命名空间，`label` 用 thunk 跟随语言切换。host 业务错误返回 `{ error, code, params }`，client 是唯一翻译点；协议错误带 `error.proto.*` 码，非法 Host 与缺少写请求标记分码。导入回滚失败和备份未清理也带可翻译码，不把 Node 系统码抄到业务 `code` 上。

## 关键服务依赖

| 平台 | 服务/注入 | 用途 |
|---|---|---|
| host | `webServer`、`skills` | 注册 HTTP 路由、写入后刷新技能目录与 Web `/` 菜单 |
| client | `slots`、`locale`、`workspaces` | 注册设置分区；双语词典与翻译（`locale: NS` 注入 t seat）；原生目录选择回退 |
| client（构建期） | `@deepseek-ai/dsh-client-runtime`、`@deepseek-ai/dsh-client-ui-slots`、`@deepseek-ai/dsh-client-locale`、`@deepseek-ai/dsh-client-ui-workspace` | `package.json` 的 `dsh.client.inject` 声明 |
