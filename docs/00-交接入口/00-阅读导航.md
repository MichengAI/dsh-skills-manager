# 阅读导航

更新时间：2026-08-15 19:10（Asia/Shanghai）

## 项目简介

`dsh-skills-manager` 是 DeepSeek Harness（DSH）的 Web 插件，在设置侧边栏提供「技能」面板：DSH 目录支持列表、启用、停用、上传和删除；公共 Agent 目录仅支持列表。

## 文档结构

| 目录/文件 | 职责 |
|---|---|
| `README.md`、`README.zh-CN.md` | 项目入口：品牌展示、功能截图、安装与使用说明 |
| `docs\00-交接入口\` | 项目导航、概览、当前状态、待办、路线图、架构基线、文档规范 |
| `docs\02-产品与业务\` | 面板使用边界与操作说明 |
| `docs\03-技术架构\` | 当前有效的领域设计（技能存储规范、接口文档） |
| `docs\05-工程交付\` | 安装、验证、发布前检查与回滚方式 |
| `docs\07-迭代归档\` | 已完成/已取消的历史迭代 |

## 推荐阅读顺序

1. `README.md`（英文）或 `README.zh-CN.md`（中文）— 了解插件能做什么、怎么装。
2. `docs\00-交接入口\01-项目概览.md` — 定位与边界。
3. `docs\02-产品与业务\01-使用说明.md` — 用户操作与权限边界。
4. `docs\00-交接入口\05-技术架构基线.md` — 技术硬约束。
5. `docs\03-技术架构\01-技能存储与规范.md`、`02-HTTP接口文档.md` — 领域权威设计。
6. `docs\05-工程交付\01-安装验证与发布.md` — 安装、验证与回滚。
7. `docs\00-交接入口\02-当前状态.md`、`03-待办与阻塞.md`、`04-迭代路线图.md` — 当前进展。
