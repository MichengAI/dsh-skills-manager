# 技能存储

更新时间：2026-08-17 02:07（Asia/Shanghai）

本文件是插件当前有效的技能存储设计。

## 技能根目录与权限

| 根目录 | 列表 | 启用/停用 | 上传/覆盖 | 删除 |
|---|---|---|---|---|
| `$DSH_HOME\skills` | 支持 | 支持 | 支持 | 支持（需确认） |
| `$DSH_AGENTS_HOME\skills` | 支持 | 不支持 | 不支持 | 不支持 |

公共 Agent 目录只读，禁止启用、停用、上传、覆盖和删除；该约束同时在客户端和服务端执行。两个根目录都不处理项目级技能目录。

## 条目形态

| 形态 | 结构 | 说明 |
|---|---|---|
| bundle | `<root>\<name>\SKILL.md` | 目录型插件，可附带脚本、模板和资源。 |
| flat | `<root>\<name>.md` | 单文件插件。 |

## 管理行为

- 列表读取插件名称、简介、形态与启停状态。
- 选择插件目录中的 `SKILL.md` 时，以该目录作为 bundle 整体复制到 `$DSH_HOME\skills`。
- 同名上传以规范化后的技能名判断，bundle 与 flat 两种形态之间也必须确认后才覆盖；覆盖会清理该名称的两种形态，只保留新上传的条目。
- DSH 技能停用写入 `disable-model-invocation: true` 与 `user-invocable: false`，以同时关闭模型调用和 `/` 手动调用；启用移除这两个字段。公共 Agent 技能不改写 frontmatter。
- 启停只替换 DSH 技能中两个调用策略行，其他 frontmatter（含引号、嵌套结构与 `|`/`>-` 块文本）按原样保留。启用删除这两行以恢复缺省可调用，不还原这两行的原始文本或行内注释。
- frontmatter 读取只解析顶层 `key: value`；嵌套字段不进入状态快照。若以后要读取 `metadata.*`，必须更换解析器。
- 每次成功写入 DSH 技能后立即使 DSH 技能目录缓存失效，并通知 Web `/` 菜单重拉候选；官方 `skills/change` 目前不会转发到浏览器，因此借用已转发的 `agent-preset/selected`（仅发送该会话当前预设，不改写预设）。
- 删除只接受 DSH 列表中的同名条目，并移除 DSH 根内对应文件或目录。
- 插件不做格式检查、重命名或自动修复。
- 单条导入全部失败时，接口返回错误；批量导入部分失败时，保留成功条目并返回每项失败原因。
