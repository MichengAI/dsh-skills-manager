# 安装、验证与发布

更新时间：2026-08-15 18:25（Asia/Shanghai）

## 安装

推荐直接从 npm 安装，无需下载源码：

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
dsh plugin --profile web add dsh-skills-manager
```

重启 DSH 后在「设置 → 技能」确认插件界面已更新。若仍显示旧界面，先确认活动 profile 已重新加载该包。若下载镜像尚未同步最新包，可在安装命令末尾添加 `--registry=https://registry.npmjs.org/`。

本地开发或未发布版本可在插件根目录执行 `dsh plugin --profile web add .`。

## npm 发布

维护者需先拥有 npm 发布权限，再在插件根目录执行：

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
npm login --registry=https://registry.npmjs.org/
npm run pack:check
npm publish
```

`prepublishOnly` 会在真正发布前执行核心测试，包内 `publishConfig.registry` 会强制指向官方 npm registry。发布后，重新执行安装命令即可获取指定版本；回滚时安装已验证版本号，例如 `dsh plugin --profile web add dsh-skills-manager@0.1.0`。

## 自动验证

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
node --check lib\core.js
node --check lib\index.js
node --check lib\client.js
node test\core-test.mjs
```

## 端到端验收

1. DSH 分组与公共 Agent 分组均可见。
2. 仅 DSH 分组能启用和停用技能；公共 Agent 分组没有修改按钮。
3. 可向 DSH 分组上传 `SKILL.md` 所在目录；同名时需要确认覆盖。
4. 仅 DSH 分组可删除，公共 Agent 分组不出现删除入口。
5. 按 ESC 时只关闭最上层确认框或上传框。

## 回滚

从 DSH Web profile 移除当前插件或恢复上一个已验证版本，然后重启 DSH。插件不会修改公共 Agent 目录中的文件结构；DSH 根目录内被覆盖或删除的技能需由安装前备份恢复。
