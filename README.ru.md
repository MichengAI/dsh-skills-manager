> DSH Skills Manager — это плагин для DeepSeek Harness (DSH), поддерживаемый сообществом, и не является официальным продуктом DeepSeek AI.

## Возможности

Объедините локальные и проектные навыки в одном месте в DSH без необходимости переключаться между каталогами различных агентов.

- **Единое мультипанельное управление**: Вкладки «Глобальные навыки», «Навыки проекта», «Обзор» и «Корзина» со мгновенным поиском и фильтрацией.
- **Просмотр по исходным репозиториям**: Переключение между структурой папок и репозиториями с точным определением источника.
- **Широкая совместимость с экосистемой**: Поддержка более 20 инструментов и CLI-сред (DSH, Shared Agent, Codex, Claude Code, Copilot, Cursor, Google Antigravity, Windsurf, Qoder, Trae).
- **Категории и Drag & Drop**: Создание категорий, перемещение карточек навыков перетаскиванием (`⋮⋮`) и включение/отключение целых категорий одним переключателем.
- **Каталоги и репозитории GitHub**: Встроенный центр обзора для поиска навыков в ClawHub и skills.sh, а также синхронизация с GitHub с автоматическим резервным копированием.
- **Создание и удобный импорт**: Создание новых навыков или импорт ZIP-архивов, папок и файлов `SKILL.md`.
- **Широкоформатный просмотр**: Адаптивное модальное окно 760px с подсветкой синтаксиса и копированием Markdown в один клик.
- **Корзина и безопасное восстановление**: Удаленные навыки DSH отправляются в корзину и могут быть полностью восстановлены в любое время.
- **Пользовательские каталоги источников**: Перенаправление внешних путей чтения без перемещения файлов.

## Установка

### Установка через агента

В диалоге с агентом DSH отправьте команду:

```text
Установи плагин @michengai/dsh-skills-manager
```

### Ручная установка

Выполните в терминале:

```bash
dsh plugin add @michengai/dsh-skills-manager
```

В среде Windows PowerShell:

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
dsh plugin --profile web add @michengai/dsh-skills-manager@latest --registry=https://registry.npmjs.org/
```

Перезапустите DSH, обновите страницу и перейдите в **Настройки → Навыки**. Для обновления плагина используйте менеджер плагинов хоста или выполните команду установки повторно.

## Настройка плагина

Плагин следует стандартным соглашениям конфигурации DSH:
> **Боковая панель → Плагины → Нажмите `Skills Manager`** (`plugins.bundle.config`).

Доступные параметры:

### 1. Значок на боковой панели (`sidebarEntry`)
- **По умолчанию**: Отключено (`false`)
- **Описание**: Отображает постоянный значок **Навыки** под разделом «Плагины» в основной боковой панели.
- **Результат**: Открывает менеджер навыков в центрированном контейнере шириной 960px в основной рабочей области.


## Руководство пользователя

| Действие | Инструкция |
| --- | --- |
| **Поиск навыков** | Переключайтесь между вкладками, сворачивайте/разворачивайте источники или используйте поиск и фильтры. |
| **Просмотр деталей** | Нажмите «Подробнее», чтобы открыть `SKILL.md` в модальном окне 760px с кнопкой копирования текста. |
| **Включение / Отключение** | Переключите переключатель в строке; влияет только на вызов в DSH без изменения исходных файлов. |
| **Смена папки источника** | В меню ➕ выберите «Папки источников…» для безопасного перенаправления путей. |
| **Управление категориями** | Создавайте категории и перемещайте навыки перетаскиванием (`⋮⋮`). |
| **Создание и импорт** | Используйте меню ➕ для создания навыков или импорта ZIP/папок. |
| **Каталоги и репозитории** | Вкладка «Обзор» позволяет находить навыки в ClawHub и подключать репозитории GitHub. |
| **Обновление навыков** | Просматривайте различия (diff) перед подтверждением обновления с резервной копией. |
| **Откат версий** | Возвращайтесь к предыдущим версиям благодаря сохраненным копиям. |
| **Корзина** | Безопасное восстановление или окончательное удаление навыков. |

### Границы установки и репозиториев

- **Обновление**: Кнопка «Обновить» проверяет только репозитории навыков. Обновление самого плагина выполняется через хост.
- **Безопасные пути**: Установка может выполняться в каталог DSH пользователя, Shared Agent (`~/.agents/skills`) или `.dsh/skills` проекта.
- **Выборочная загрузка Git**: Загружаются только каталоги, содержащие `SKILL.md`.

### Пользовательские источники

Для добавления агента, отсутствующего в списке, воспользуйтесь меню ➕ и выберите «Папки источников…».

### Предустановки агентов (Agent Presets)

Плагин автоматически находит предустановки агентов с выделенными каталогами навыков в DSH и размещает их в конце общего списка:
- **Официальные встроенные предустановки** (например, Режим создателя): встроенные навыки доступны строго в режиме «только чтение» для просмотра деталей без лишних переключателей;
- **Пользовательские предустановки**: ваши собственные режимы с `customSkillDirs` полностью соответствуют стандартным навыкам — включение/выключение отдельных навыков или всего источника, категории и заметки, создание, импорт, установку и удаление из репозиториев, перемещение в Корзину и восстановление. Пути, пересекающиеся с глобальными каталогами, надежно блокируются для защиты от случайного удаления, а относительные пути в целях безопасности отображаются только для чтения (укажите абсолютный путь для полного управления).
